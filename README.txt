# Vision Care Opticals — Sample Website

Open `index.html` in a browser to view the website.

## Replace these details
- Shop name/logo
- Address
- Phone / WhatsApp number
- Opening hours
- Product names, brands and prices

## Add products
Edit `products.js` and add another product object with:
name, brand, category, price, image

Put the product image inside the `images` folder and reference it from the product object.

## Free hosting
This static website can be deployed on GitHub Pages, Cloudflare Pages, Netlify or Vercel.
